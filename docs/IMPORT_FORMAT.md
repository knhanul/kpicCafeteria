# 마이그레이션 XLSX 형식

필수 시트:

1. `01_배식설정`
2. `02_메뉴기준정보`
3. `03_재료기준정보`
4. `04_재료별칭_선택`
5. `05_메뉴별재료_기준`
6. `06_식단이력_이관`
7. `07_식단재료_이관`

기준 파일은 운영자가 직접 업로드한 XLSX를 사용합니다.

- 중식 기본 계획식수: 400명
- 석식 기본 계획식수: 100명
- 메뉴별 레시피는 100인 기준
- 과거 식단 재료는 당시 수량을 스냅샷으로 보존
- 수량 또는 단위가 비어 있어도 이관하며 통계 중량값만 제외
- `06_식단이력_이관`의 선택 열 `메인메뉴여부`(`Y`/`N`)는 식단 메뉴의 메인 메뉴 표시(`is_representative`)로 저장합니다. 한 일자×배식유형에 `Y`는 최대 1건이며, 잘못된 값이나 복수 `Y`는 행번호와 함께 Preview 오류로 표시됩니다. 열이 없는 기존 파일은 메뉴순서가 가장 빠른 `주찬`을 자동 지정합니다. 자세한 규칙은 `data-migration-guide.md`를 참고하세요.
- `05_메뉴별재료_기준.레시피명`은 레시피 이름으로 저장합니다(비우면 `기본 레시피 vN`). `06_식단이력_이관`의 선택 열 `레시피명`이 있으면 그 식단 메뉴를 같은 메뉴ID의 해당 레시피에 연결합니다. 같은 메뉴의 이름·구성 충돌이나 `05`에 없는 이름은 행번호와 함께 Preview 오류로 표시됩니다.
