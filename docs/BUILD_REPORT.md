# V2 변경 보고서

## 반영 기능

- 메뉴 1개에 여러 레시피 등록
- 재료 구성 기준 레시피 중복 감지
- 수량 변경은 기존 레시피 수정
- 식단 메뉴 추가 시 레시피 선택
- 식단에서 적용 레시피 변경
- 메뉴·재료 목록과 편집 패널 통합
- 메뉴 레시피 재료 엑셀 붙여넣기 그리드
- 식단 작성 패널의 구성 참고 카드 제거
- 기간 선택형 식단 구성 대시보드
- 기존 PostgreSQL 스키마 호환 업그레이드

## 검증

- JavaScript 문법 검사
