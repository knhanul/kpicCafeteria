## 예상 결과

```text
menus: 2
ingredients: 3
recipe_rows: 2
meal_history_rows: 2
meal_ingredient_rows: 2
```

이 예시는 사람이 검토하기 위한 Sample이며, DB ID를 직접 포함하지 않는다. 실제 Apply는 반드시 Import Preview 후 수행한다.

## 현재 Repository의 실제 Workbook

현재 Repository에는 기존 Canonical 입력 예시가 다음 위치에 있다.

```text
data/source/식재료_마이그레이션_기준정보.xlsx
```

이 파일은 `MigrationImporter.preview()`에서 필수 Sheet/행 구조 검증 대상으로 사용할 수 있다. 최근 Preview 결과는 `ready=True`, 오류 0건이었다.
