# Canonical Migration Template

표준 Migration XLSX를 작성할 때 이 문서와 `canonical-migration-contract.json`을 기준으로 사용한다. 실제 XLSX Sheet 이름은 다음과 같다.

```text
01_배식설정
02_메뉴기준정보
03_재료기준정보
04_재료별칭_선택
05_메뉴별재료_기준
06_식단이력_이관
07_식단재료_이관
```

## 빈 행 Template

### 01_배식설정

```text
배식유형 | 기본계획식수 | 기본배식시간 | 사용여부 | 설명
```

### 02_메뉴기준정보

```text
메뉴ID | 메뉴명 | 통계집계메뉴명 | 메뉴역할 | 사용여부 | 검토상태
```

### 03_재료기준정보

```text
재료ID | 표준재료명 | 통계분석군 | 기본단위 | kg환산계수 | 분석제외 | 사용여부 | 검토상태
```

### 04_재료별칭_선택

```text
원재료별칭 | 재료ID | 표준재료명 | 출처
```

### 05_메뉴별재료_기준

```text
메뉴ID | 메뉴명 | 레시피명 | 재료ID | 표준재료명 | 100인기준수량 | 단위 | 원본행 | 원본비고 | 검토상태
```

### 06_식단이력_이관

```text
일자 | 배식유형 | 계획식수 | 배식시간 | 메뉴순서 | 메뉴ID | 메뉴명 | 메뉴비고
```

### 07_식단재료_이관

```text
일자 | 배식유형 | 메뉴순서 | 메뉴ID | 메뉴명 | 재료순서 | 재료ID | 표준재료명 | 원본재료명 | 수량 | 단위 | 원본비고 | 원본행
```

## 입력 규칙

- DB PK는 입력하지 않는다.
- `메뉴ID`, `재료ID`는 원본에서 확인된 안정적인 Migration Key를 사용한다.
- `메뉴명`, `표준재료명`, 날짜, 배식유형은 필수 의미를 확인한다.
- 알 수 없는 Ingredient를 이름으로 자동 연결하지 않는다.
- 단위와 수량을 추정하지 않는다.
- `cooking_instruction`, `cooking_note`는 사용하지 않는다.
- 업로드 후 반드시 Import Preview를 실행한다.

## 검증 순서

```text
파일 구조 확인
→ 필수 Sheet 확인
→ 필수 Column 확인
→ Key 중복 확인
→ 날짜/배식유형 확인
→ 메뉴/재료 참조 확인
→ 수량/단위 확인
→ Review 목록 확인
→ /api/setup/import/preview
→ 사람 승인
→ Backup
→ /api/setup/import/apply
```
