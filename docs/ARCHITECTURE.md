# 아키텍처

## 공통 주간 작업공간

왼쪽 월~금 식단표와 오른쪽 업무 패널을 공유합니다.

- 식단 작성
- 조리지시서
- 보존식 기록
- 실제 식수

식단 작성 화면에는 통계 카드를 표시하지 않습니다. 통계는 별도 대시보드에서 조회합니다.

## 기준정보 화면

메뉴와 재료는 팝업 대신 목록과 편집 패널을 한 화면에 배치합니다.

```text
목록 패널 | 등록·수정·삭제 패널
```

메뉴 편집 패널에는 다중 레시피 목록과 엑셀형 재료 입력 그리드가 포함됩니다.

## 문서 출력

```text
공통 DTO
├─ HTML 미리보기
├─ Playwright PDF
└─ 등록 HWPX 템플릿
```
