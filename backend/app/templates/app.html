발주 관리

식단에 포함된 재료의 필요량을 자동으로 확인하고 발주량·발주일·배송일을 관리합니다. 필요량은 식단 기준으로 자동 계산되며, 발주량은 실제 주문 상황에 맞게 수정할 수 있습니다.

기본 데이터 관리

HWPX 문서 양식과 배식 기본값을 관리합니다.

운영 대시보드

이번 달 급식 운영 상태를 한눈에 확인합니다.

식수 통계

계획·실제 식수와 편차를 분석합니다.

메뉴 통계

메뉴 사용 횟수와 반복·미사용 메뉴를 분석합니다.

식재료 통계

재료군·개별 재료의 사용량을 분석합니다.

운영 기록 통계

식단 작성·조리지시서·보존식·실제 식수 완료율을 확인합니다.

사용자 관리

사용자 계정을 등록하고 권한과 상태를 관리합니다.

시스템 데이터 백업

현재 구내식당 시스템의 모든 업무 데이터를 백업파일로 저장합니다. 문제가 발생했을 때 시스템 데이터를 복구하는 데 사용할 수 있으므로 정기적으로 별도 저장장치에 보관하는 것을 권장합니다.

Excel 데이터 아카이브

식단, 조리지시, 보존식 및 기준정보를 Excel 파일로 저장합니다. Excel에서 직접 내용을 확인할 수 있으며 장기보관용 자료로 사용할 수 있습니다. 이 파일은 시스템에 직접 복구하는 백업파일은 아닙니다.
