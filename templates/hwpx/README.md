# HWPX 템플릿 작성 규칙

시스템의 `HWPX 문서` 메뉴에서 정상 HWPX 템플릿을 등록합니다. 서버는 템플릿 패키지를 새로 만들지 않고 텍스트 플레이스홀더와 섹션만 복제합니다.

## 보존식 기록지

한 페이지에 3개 기록지 양식을 만들고 아래 플레이스홀더를 각각의 셀에 입력합니다.

- `{{R1_DATE}}`, `{{R1_COLLECTION_HOUR}}`, `{{R1_COLLECTION_MINUTE}}`, `{{R1_MANAGER}}`
- `{{R1_MENU}}`, `{{R1_FREEZER_TEMP}}`, `{{R1_DISPOSAL_DATE}}`, `{{R1_COLLECTOR}}`, `{{R1_COLLECTION_TIME}}`
- 같은 방식으로 `R2_...`, `R3_...`

식단명 행은 한글에서 고정 높이로 설정합니다. 데이터가 1~2건이어도 빈 양식은 유지됩니다.

## 조리지시서

한 날짜를 한 페이지로 만든 뒤 아래 플레이스홀더를 큰 셀에 배치합니다.

- `{{DATE}}`
- `{{LUNCH_TITLE}}`, `{{LUNCH_BODY}}`
- `{{DINNER_TITLE}}`, `{{DINNER_BODY}}`

날짜 수만큼 템플릿 섹션이 복제됩니다.

## 식단표

2주, 평일 10칸 양식에 다음 플레이스홀더를 사용합니다.

- `{{D1_DATE}}`, `{{D1_LUNCH}}`, `{{D1_DINNER}}`
- 같은 방식으로 `D2`부터 `D10`까지

플레이스홀더는 가능하면 하나의 글자 스타일(run)로 입력해 주세요. 시스템은 분리된 run도 합쳐서 치환하지만, 플레이스홀더 문단에는 다른 텍스트를 섞지 않는 것이 안전합니다.
